Per-college **public suggestion box** (replaced the old committee/mess/praise/stats app). Next.js 16 (App Router, server-rendered, Turbopack), Supabase (project `gmkzcxvgbhhvznbkxlae`), deployed on Vercel: **https://mss-feedback.vercel.app**. ## Current state (all working, verified)

- **QA suite passes 28/28** vs prod: `QA_AUTH_BYPASS=1 node scripts/qa.mjs` (needs `.env.local`; uses perftest111@gmail.com / PerfTest@123). Do not run against prod without bypass — `/admin` behavior differs. Covers anonymous board + global feed, legacy redirects (307), 3/day limit, column privacy (user_id hidden), self-vote 403 / foreign-vote 201 / dup 409, XSS, delete-own, super-admin `/admin` under bypass.
- **Product is now a simple, per-college suggestion box.** Reading is OPEN — the proxy has no login wall; signing in only names the poster/voter/commenter. Mess/praise/stats/onboard modules, committee roles, admin subpages, ratings, ban UI were all **stripped from app code**. A **Report/Moderation flow was added**: `components/ReportButton.tsx` (prechecks via RPC `my_flagged_complaint_ids`, inserts into `complaint_flags`) on feed cards + detail pages, and `/admin` shows a client-side **Flags panel** (`app/admin/flags.tsx`) for hide/restore (`setComplaintHidden`) and clear-flags (`clearFlags`) — server actions gated on `superCtx()`'s `isCreator`. Non-creators get a **read-only preview** of `/admin` (no redirect), write actions throw. `NEXT_PUBLIC_AUTH_BYPASS=1` stays set in prod only so the QA admin check passes; the isCreator gate closes the mutation surface. The DB is intentionally untouched — `status`, `resolution_note`, `closed_by`, `admin_members`, `is_banned`, praise/rating/menu tables still exist with data preserved; the app just stops using them.
- **Rate limits (DB-enforced)**: 100 upvotes/day and 50 comments/day via `daily_votes_left(uid)` / `daily_comments_left(uid)` security-definer helpers against the Asia/Kolkata day, wired into the "insert upvote"/"insert comment" RLS policies (overrides via settings row `daily_vote_limit`/`daily_comment_limit`). Hardening: authenticated users can no longer UPDATE `profiles`; `trg_comment_parent_check` blocks replies whose parent belongs to another complaint; `trg_cleanup_complaint_photos` deletes bucket objects when a complaint is deleted; pg_trgm GIN indexes on `complaints.title`/`description` power search. Search is cached (`unstable_cache` revalidate 30, tag `complaint`). Complaint photos are served via `next/image` (remotePatterns for `gmkzcxvgbhhvznbkxlae.supabase.co`) and uploads use `cacheControl: 31536000`.
- **Routing** (`proxy.ts` at repo root, Next 16 — middleware convention removed): `/{slug}` always rewrites to the board with `INST_HEADER` (no session required); bare `/` is the **global "All boards" feed** (no cookie injection — deterministic); legacy `/mess`, `/praise`, `/stats`, `/onboard` redirect to `/` (top-level) or `/{slug}` (slug-scoped). Legacy names stay in `RESERVED` so they're not mistaken for college slugs (fixed during refactor).
- **Home (`/`)** = global Reddit-style feed of every college's complaints (`lib/feed.ts` → `getGlobalFeed`, cached `unstable_cache` tags `["complaint"]`, revalidate 30) with **Hot / Top / New** sorting (`SortBar`, default Hot via `hotScore`). Cards show college + category chips, upvotes, comment count, meal session, relative time, photos.
- **College board (`/{slug}`)** = that college's "Suggestion box" with its **segments** as category chips (Mess 🍽 + sub, WiFi, Hostel, Library, Labs, Washroom, Sports, Parking, Other…), **Hot / Top / New** sorting, and the "File a complaint" button (→ `/{slug}/complaints/new`). College switcher dropdown to jump boards (`components/CollegeSwitcher.tsx`). NOTE: the proxy rewrites every `/{slug}` board to the internal route `/`, so `/` and `/{slug}` share the same route module — **client-side navigation between them no-ops** (same router tree, no re-render; neither `router.push` nor `<Link>` fixes it, verified repeatedly). Board switches must use **plain `<a>` full-document navigation**: the dropdown items are `<a>`, and NavBar's Home/logo + Top boards are `<a>` (with `eslint-disable-next-line` for `no-html-link-for-pages`). Links to detail/new/profile/admin/login are safe as `<Link>` (distinct route modules). Post/delete land back on `/{slug}` (not `/`).
- **Design v4 "Loud and sound" (formerly REVERB), indigo editorial**: product is **Loud and sound — "Louder together"** (see `app/layout.tsx` metadata, `components/ReverbMark.tsx` for the ReverbMark abstract monogram + ReverbLogo wordmark). One **indigo** accent — light `--accent:#4F46E5`, bg `#F6F6F9`; dark bg `#0D0E15`, accent `#7679FF` — with radial indigo gradients on `body`. **Manrope variable** as display font (`@fontsource-variable/manrope`, `--font-display`). Tokens keep the same names (`accent/accent-strong/accent-soft/accent-ink/surface/surface-2/...`); sharp corners (btn/input `0.625rem`); hairline borders. Key utilities still `.card/.card-hover/.btn-primary/.chip/.section-label/.tap`. Layout is **top app bar only — no sidebar, no right rail**: `NavBar.tsx` = sticky blur bar (ReverbLogo + centered search box + ThemeToggle + "File complaint" + avatar) + mobile 3-tab bottom nav (Home/Post/Profile). Search runs against a real page: `app/search/page.tsx` + `lib/feed.ts` `searchComplaints()` (ILIKE on title/description); the app-bar SearchBox does `router.push(/search?q=...)`. `LiveFeed.tsx` renders the feed container with a LIVE ribbon + `router.refresh()` every 30s. Cards (`FeedCard.tsx`, client) are hairline rows w/ whole-card click (stopPropagation on anchors/buttons), left vote rail, college badge+name, category, photo tiles, and a Save/Share action row (`SaveButton.tsx` toggles `saved_complaints`, `ShareMenu.tsx` WhatsApp/copy/native). SortBar = editorial underline tabs (`.sort-tab`). Stagger/animations stay removed; `body` keeps `optimizeLegibility` + antialiasing.
- **Complaint detail**: upvote/downvote toggle, comments (React-escaped), delete-own → `router.push("/")`. No status/resolution/close/flag. Documented API contract (RLS): self-vote 403, dup 409, else 201, unvote 204.
- **New complaint**: logged-out → sign-in prompt banner; meal-session picker only when the selected category `is_mess`; photos ≤2 / ≤10MB / compressed; **anonymous is default ON** (toggleable); **3/day limit** via `complaints_left_today` RPC (blocked insert = 403). Post lands back on `/{slug}`.
- **Profile**: name + college badge (from `profiles.institution_id`) + **karma** (upvotes received) + **Saved** list (from `saved_complaints`) + "My complaints" + sign out. **Roll numbers removed from the UI** (DB column stays, just never shown). Logged-out → inline sign-in card (no redirect). Comments on detail pages are **nested threads** (`app/complaints/[id]/detail-actions.tsx` — CommentThread/ThreadedComments, replies inline, indent cap depth 4).
